# vivilen_model
Модель предсказания параметров цветности продукта Vivilen в зависимости от параметров качества входного сырья и некоторых технологических параметров
## Запуск

1. Установить зависимости:
   pip install -r requirements.txt

2. Положить входные данные в data/input.csv

3. Запустить:
   python inference.py --input data/input.csv

## Формат входных данных
- Таблица аналогичная обучающей и тестовой, которая лежит в папке data
- Необязательные колонки: 'Номер партии'
- Минимум 3 строки истории для генерации корректных лагов

## Выходные данные
- Прогноз L, a, b для следующей партии
- Зона допуска (ЗЕЛЁНАЯ / ЖЁЛТАЯ / КРАСНАЯ)
